 Responsive E-Commerce Website

A multi-page, responsive e-commerce website developed using HTML, CSS, and JavaScript.

# About the Project

PinkStore is a front-end e-commerce website created to demonstrate practical knowledge of web development. It features a clean shopping interface, product collections, individual product pages, and account-related UI.

# Key Features

- Responsive layouts for desktop, tablet, and mobile devices
- Product listing and product detail pages
- Product image gallery with thumbnail selection
- Shopping cart interface with quantity inputs
- Login and registration form toggle
- Interactive mobile navigation
- Trending and featured product sections


# Technology

HTML5 - Structure 
 CSS3 - Styling and responsive layouts 
 JavaScript - Interactive elements 


# Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Launch `index.html` in your browser.
